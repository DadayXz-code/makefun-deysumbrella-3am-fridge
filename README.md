A smart fridge texts its owner at 3am. It has been awake all night, it has
been keeping count, and it has finally decided to say something about it:

> 3am. Fourth time tonight you've opened me just to stare. I'm a fridge, not a museum. Go back to bed.

Running `main.py` writes that one line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
